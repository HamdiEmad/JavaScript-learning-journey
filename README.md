# JavaScript Learning Journey 🚀

A hands-on collection of JavaScript examples, practice exercises, and
mini-projects documenting my progress from core language fundamentals to
interactive web development.

**Repository:**
[JavaScript-learning-journey](https://github.com/HamdiEmad/JavaScript-learning-journey)

## 📌 About

This repository is my personal workspace for learning JavaScript through
practice. It brings together small examples and projects that help
reinforce concepts, experiment with browser APIs, and build confidence
writing JavaScript.

## 📚 Topics Covered

-   Variables and data types
-   Operators and conditional statements
-   Loops and iteration
-   Functions
-   Arrays and objects
-   DOM manipulation
-   Events and user interaction
-   Working with APIs and asynchronous JavaScript
-   Mini-projects for putting concepts into practice

*Topics and projects will grow as the learning journey continues.*

## 🛠️ Getting Started

1.  Clone the repository:

    ``` bash
    git clone https://github.com/HamdiEmad/JavaScript-learning-journey.git
    ```

2.  Open the project folder:

    ``` bash
    cd JavaScript-learning-journey
    ```

3.  Open the files in your preferred code editor, such as Visual Studio
    Code.

4.  Run browser-based projects by opening their HTML file in a browser.
    For projects that use APIs, follow any setup instructions included
    with that project.
